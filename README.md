# 项目应收管理系统（MVP）

面向市级管理员、区县管理员和区县填报人的中文内部管理工作台。本地开发时使用本地 D1/R2；发布到 OpenAI Sites 时由托管的 D1 保存业务数据，R2 保存合同、回款凭证和催缴函件。

## 已实现范围

- 应收工作台：待确认、剩余应收、部分回款、逾期未留痕等运营指标与明细。
- 项目管理：手工新增、合同附件、付款节点、详情与历史项目。
- 应收管理：待确认应收、市级确认、核销状态、逾期风险和法律风险。
- 回款流水：多笔回款、凭证、超额阻止、作废并追加更正。
- 催缴中心：微信、面谈、正式函件、领导介入、附件与不可覆盖时间线。
- 导入中心：三份 Excel 模板、预览、逐行校验、有效行提交和错误 CSV。
- 审计日志：实体、字段、原值、新值、原因、来源、操作人和操作时间。
- 风险设置：市级管理员调整阈值，规则变更写入审计。
- 服务端角色权限与区县数据隔离。

## 本地运行

```bash
pnpm run dev
```

浏览器访问：`http://localhost:3000/`

首次访问会幂等创建数据库结构和匿名演示数据；再次启动不会覆盖已有业务数据。

接口集成测试会自动使用一次性的临时 D1/R2 状态目录和空闲端口，结束后清理临时状态，不会向日常演示数据库写入“自动化验收”数据。

## 演示身份

- 市级管理员：查看全市、创建项目、确认应收、调整风险规则及兜底处理。
- 区县管理员：查看本区、维护付款节点、登记及更正回款和催缴、查看本区审计。
- 区县填报人：查看本区、登记回款和催缴、上传附件。

页面右上角可切换角色和碑林、雁塔、莲湖三个匿名区县。身份和区县范围保存在 HttpOnly 演示会话 Cookie 中，服务端不接受客户端直接声明权限。

## 验证

```bash
pnpm run test:unit
pnpm run test:integration
pnpm run build
pnpm run db:generate
```

- 单元测试覆盖日期、金额、核销、逾期风险、法律风险、项目归档和权限矩阵。
- 接口测试覆盖跨区拒绝、完整业务链路、作废更正、附件限制、三类导入和审计证据。
- `db:generate` 应显示 11 张表且无未生成的结构变更。

## 一期边界

本 MVP 不包含正式账号或单点登录、交付模块、领导大屏、CRM/计费接口、AI 合同解析、历史数据迁移和公开网站级安全承诺。Sites 部署默认保持仅所有者可访问。
